# NightingaleDanceInfo

ナイチンゲールダンスの情報をまとめる非公式ホームページです。

## 開き方

`index.html` をブラウザで開くと表示できます。依存パッケージやビルド手順は不要です。

## GitHub Pages

このサイトは静的HTMLなので、GitHub Pagesでは `main` ブランチのルートを公開元にすれば表示できます。

1. GitHubで空のリポジトリを作成
2. このフォルダをpush
3. Repository Settings > Pages
4. Sourceを `Deploy from a branch` に設定
5. Branchを `main`、Folderを `/root` に設定

## 更新箇所

- ニュースカード: `script.js` の `newsItems`
- 画面デザイン: `styles.css`
- 本文とリンク: `index.html`

## 注意

このサイトはファン制作の非公式ページです。公演情報、販売状況、出演者変更は公式プロフィール、FANYチケット、劇場ページで確認してください。
